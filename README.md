## English

### Features

- **Same-tab switching:** click the brain button to switch between Markdown and a mind map in the same tab.
- **Split preview:** open a separate preview with the Split button. Choose side-by-side or stacked panes in settings; saved Markdown changes refresh the preview automatically.
- **Heading hierarchy:** the filename is the root. Markdown headings form branches; paragraphs, quotes, lists, tables and code stay in their corresponding node's body.
- **Two map directions:** switch between horizontal (left to right) and vertical (top to bottom) using the header or **⋯** menu, independently of pane placement.
- **Summary or scrolling content:** by default, nodes show up to 140 characters across four lines. Enable **节点内滚动** in settings or the **⋯** menu to show full content with scrolling above 360px in height.
- **Right-side details:** click a node title to read its full formatted content in a scrollable panel. Click another title to switch content; close with **×** or by clicking blank canvas. Available in both content modes.
- **Independent folding:** circled plus/minus buttons fold node bodies; connection endpoints fold branches. The header also offers one-click folding or expansion of all bodies, preserving the current zoom.

- **Drag and arrange:** drag nodes to reposition them; connectors follow. Click **自动** to restore automatic arrangement.

## 中文

### 功能简介

- **同标签切换：** 点击大脑按钮，在当前标签内切换 Markdown 与思维导图。
- **分屏预览：** 点击 Split 按钮打开独立预览；设置中可选择左右并排或上下排列，源 Markdown 保存修改后自动刷新预览。
- **标题层级：** 文件名作为根节点，Markdown 标题形成分类分支；段落、引用、列表、表格和代码归入对应节点的正文。
- **两种导图方向：** 通过顶部按钮或 **⋯** 菜单切换水平（从左到右）与垂直（从上到下）布局，与分屏位置独立。
- **摘要／滚动正文：** 默认最多显示 140 个字符、4 行摘要；在设置或 **⋯** 菜单开启**节点内滚动**后显示完整正文，超过 360px 高度时滚动阅读。
